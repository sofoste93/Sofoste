# Security policy

## Supported version

Only the latest published APK receives security fixes. Older releases remain
available as a transparent project history and should not be used for a new install.

## Reporting a vulnerability

Do not open a public issue for authentication, privacy or data-exposure concerns.
Send the report to `info@sofoste.de` with the affected version, reproduction steps
and the practical impact. Please omit real student data, passwords, session cookies
and access tokens.

Official APKs are attached to GitHub Releases in this repository and use the release
certificate documented in the README. APK files distributed elsewhere are not
official Sofoste builds.
